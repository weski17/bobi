# ADR-0015: MCP client and the code graph server

- Status: Accepted (2026-10-19, phase 3 plan approved by the project owner)
- Date: 2026-10-19

## Context

Requirement 8 asks for local and remote MCP servers, enabled per mode; requirement 16 for own MCP servers, starting
with a code graph. The engine has an MCP client (SDK 2.0) and accepts servers per location through the plugin API
(`ctx.mcp.transform`). By default it offers MCP tools only through its "Code Mode" interpreter and can run an OAuth
flow that registers through a vendor service.

## Decision

- **Configuration** in `config.jsonc` (`mcp.servers`, `mcp.timeout`), global and per project – project servers only
  with project trust (ADR-0014), because a local server is code. Server names: lowercase, digits, hyphens (no `_`,
  tools are `<server>_<tool>`). Credentials only as `${ENV_VAR}` (optionally `Bearer ${…}`); a server with a missing
  variable is disabled instead of started with an empty token.
- **Registration** per project by `@bobi/core`; `codemode: false` so every MCP tool is a separate tool that modes can
  hide and each call is approved; **OAuth off** (`oauth: false`).
- **Per mode:** group `mcp` (all servers) or `[mcp, { servers: [...] }]`; other configured servers get deny rules and
  are hidden. Modes without `mcp` also cannot use the engine's MCP resource tools.
- **Approvals:** every MCP call asks (policy `*_*`); auto-approve with `{ "action": "mcp", "resource": "<server>_*" }`.
  Results are marked as untrusted data.
- **Code graph** (`mcp-servers/code-graph`): TypeScript compiler API over TS/JS sources (no `node_modules`, build
  output, `.gitignore`/`.bobiignore`'d files); tools `find_symbol`, `callers`, `callees`, `call_path`,
  `dependencies`, `dependents`; re-indexes when files change. Built in for every project, used by modes with `mcp`
  (built-in: `advanced`).
- In the sandbox, local servers run inside the container; remote servers need an egress allowlist entry.

## Consequences

- Static analysis: dynamic calls, reflection and calls through untyped values are not visible.
- MCP tools become available a moment after a server connects; the first message right after start may not offer them.
- Other languages (COBOL in phase 6) come as separate servers.
