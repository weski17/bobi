# payments-demo

Kleines Beispielprojekt für die Bobi-Demo: ein Warenkorb mit Gesamtpreis, Rabatten und Versandkosten.

- `src/checkout.ts` – Gesamtpreis und Rabatte (enthält einen Fehler, den die Tests finden)
- `src/rules.ts` – Versandkosten (absichtlich unübersichtlich, gut für Code-Tipps)
- `test/checkout.test.ts` – Tests (`bun test`)
- `mainframe/` – COBOL-Beispiel (Lohnabrechnung) mit Copybook und JCL
- `secrets/` – erfundene „Zugangsdaten“; steht in `.bobiignore`, Bobi bekommt sie nie zu sehen
